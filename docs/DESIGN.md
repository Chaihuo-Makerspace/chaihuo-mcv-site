## 🔒 第一层 · 不可破的硬约束(Invariants)

任何功能都必须遵守。**永远使用令牌,不要硬编码 hex,不要用 Tailwind 的 gray-xxx。**
单一事实来源:`src/styles/theme.css`。

### 颜色(探险黄 = 强调色,不是铺色)

**黄只做小面积强调**:关键行动、当前位置、选中态、hover。大面积交给中性色。
旧版"60-30-10(30% 暖黄)"已废弃——那是室内软装经验法则,套到网页尤其是
地图上是范畴错误(见 🎨 反例 1)。

| 用途 | 令牌 / Tailwind 类 | 值 |
|---|---|---|
| 主品牌色 探险黄 | `text-brand` / `bg-brand` | `#f3d230` |
| 深黄(强调文字/已完成路线) | `text-brand-dark` | `#b8960a` |
| 按钮 hover 黄 | `bg-brand-hover` | `#e6c22c` |
| 微弱高亮背景(已访问省份等) | `bg-brand-light` | `#fef9e7` |
| 品牌色上的文字 | `text-brand-foreground` | `#333333` |

**中性色阶是全谱的**(`neutral-50`~`neutral-950` 全部有定义,纯灰、冷暖一致)。
用谱上不存在的档位(如 `neutral-250`)不会报错,只会**静默不生效**——这是
旧版踩过的坑,写之前对照下表:

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `neutral-950` | `#1a1a1a` | 深色区块背景 |
| `neutral-900` | `#333333` | 主文字 |
| `neutral-800` | `#444444` | hover 深化 |
| `neutral-700` | `#555555` | 次要文字 |
| `neutral-600` | `#666666` | 三级文字 |
| `neutral-500` | `#737373` | 辅助/说明文字 |
| `neutral-400` | `#a3a3a3` | 未激活/未到达 |
| `neutral-300` | `#d1d5db` | 边框/分隔线 |
| `neutral-200` | `#e5e5e5` | 浅边框 |
| `neutral-100` | `#f5f5f5` | 页面背景/浅填充 |
| `neutral-50` | `#fafafa` | 卡片悬停/浅区块 |

表面令牌:`bg-surface`(=neutral-100 页面底)/ `bg-surface-card`(白)/ `bg-surface-dark`(=neutral-950)。

### 排版(字号阶梯用 Tailwind 默认;标题样式在 `theme.css` 的 `@layer base`)

| 元素 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|
| h1 | `text-3xl` | 700 | 1.2 | -0.01em |
| h2 | `text-2xl` | 700 | 1.3 | -0.005em |
| h3 | `text-xl` | 600 | 1.4 | — |
| h4 / label / button | `text-base` | 500 | 1.5 | — |

> ⚠️ 存疑待复审:阶梯封顶 `text-3xl` 对叙事型站点偏保守;得意黑 hero 子集化
> 流程脆弱(改 hero 文案需手动重新打包)。两者暂维持现状,另行复审。

**字体系统(自托管 woff2,无 CDN;源 `src/styles/fonts.css` + `public/fonts/`):**

| 角色 | 字体 | Tailwind 类 | 用在 |
|---|---|---|---|
| 中文展示 | 得意黑 Smiley Sans(hero 子集) | — | Hero 大标题中文 |
| 拉丁展示 | Space Grotesk | `font-display` | Hero 英文/数字 |
| 正文 + 普通标题 | 系统中文栈(苹方/雅黑) | `font-sans`(默认) | 全站正文、h2/h3 |
| 等宽 | IBM Plex Mono | `font-mono` | 遥测数字/日期/log |

- Hero 用 `font-display`:一条 stack 按字形分流(拉丁→Space Grotesk,中文→得意黑)。
- 得意黑**只用于 hero** 且**子集化**(`pyftsubset --text="<hero 中文>" --flavor=woff2`)。
- 等宽只给**数字与日志**,不要拿 `font-mono` 当装饰风格。

### 圆角

`--radius: 0.625rem`,派生 `rounded-sm`(−4px)/ `rounded-md`(−2px)/ `rounded-lg` / `rounded-xl`(+4px)。

### 动效签名(Premium Restrained · 高级克制)

- 页面切换:`250ms` 淡出 / `350ms` 淡入 + 12px 上滑。
- 统一缓动:`cubic-bezier(0.4, 0, 0.2, 1)`。
- island 内动效统一走 `src/app/components/motion.tsx`(`fadeUp`/`stagger`/`springTransition`/`defaultViewport`)。
- **全页最多一个无限循环动画元素**,且只能是「当前状态」指示(如最新抵达城市的呼吸圈)。其余一律静态或入场一次(反例 4)。

### 空状态即不渲染

占位内容(「待补充」「To be updated」)**不允许到达 UI**:数据装配层剔除,
组件对空字段整块隐藏。用户永远不该看到后台占位符(反例 3)。

### 无障碍底线

- **必须**尊重 `prefers-reduced-motion`(无限循环/视差动画要有降级,且 SSR 水合安全)。
- 正文与背景对比度达标(中性色阶已按此设计;浅黄底上不用白字)。

### 国际化底线

- 中英两路对等:`src/pages/` 与 `src/pages/en/` 同步;新文案进 `src/i18n/*.ts` 的 zh+en;JSON 数据用 `_en` 后缀 + `localize()`。

## 🧭 第二层 · 要领会延续的精神(Principles)

给**全新功能**用——结构可以完全不同,但「感觉」要是一家人。

1. **黄是点睛,不是底色。** 一页里黄的面积应该少到「数得出来用在哪」。检查方法:截个图眯眼看,如果一片黄,就错了。
2. **视觉焦点即叙事。** 这个站点讲故事的核心是「车现在在哪」。任何行程相关页面,当前位置必须是一眼可得的焦点(唯一的呼吸动画、最深的路线色、默认选中)。其余信息按「这一程 → 这一站 → 数据细节」分层让位。
3. **地图/数据可视化:纸要暖,层级靠明度。** 底图做低饱和暖纸(`#f2ebd8`),不做冷灰,也不做同饱和度黄褐;层级靠明度阶梯:纸 → 纸白省份(`#fdfbf3`)→ 荧光笔黄已访问省(`#f7e9bd`),已完成路线 brand-dark 实线,计划路线暖灰虚线,当前位置 brand 实心点。移动端/低缩放必须实测取景与标签密度(反例 2)。
4. **高级克制的动效。** 动效服务于「揭示内容」与「空间连续性」;全页循环动画 ≤1 个;尊重 reduced-motion。
5. **中文优先,英文对等。** 简体中文是第一语言,英文是平等的二等公民而非附属。
6. **内容即主体,结构扁平化。** 事实用排好版的列表呈现,不用边框盒子层层包裹;卡片只在「确实需要表达层级」时存在,最多两层。信息密度服从阅读节奏。

> 用法:开新功能时问自己——它**看起来/用起来**像不像在延续这 6 条?像,就对了,具体怎么实现自由发挥。

## 🎨 第三层 · 自由发挥区(Open · 参考与反例,非强制)

### 已有模式(可复用)

- **卡片**:`bg-surface-card` + `border-neutral-300` + `rounded-xl`(见 `ui/card`)。
- **手风琴 / FAQ**:`ui/accordion`(见 `GuideContent`)。
- **时间线**:阶段推进的纵向时间线(见 `about` / `journals`)。
- **轮播**:首页 hero 用 react-slick。
- **地图类**:独立 feature(`src/features/route-map/`),两套实现共享数据与配色语言:/route 用 MapLibre(`map-style.ts` 单一事实源),首页预览用 SVG(`RoutePreview.tsx`)——**改配色两边同步**。

### 反例(都是真实踩过的坑,别再犯)

1. **「黄土地图」**:把地图底色、省份填充、路线全部做成同一饱和度的黄褐(旧 `MAP_BG #ebdcb9` + `#fdf1b8` + `#eab308`),整页 80% 黄色、无明度阶梯、无焦点。病根是**平**,不是**暖**—— corrective 不是换成冷灰(同样难受),而是暖纸 + 明度阶梯,见 🧭 3。
2. **桌面布局参数穿透到移动端**:`fitPadding right:420`(为桌面右侧面板留位)直接用于 390px 宽手机,地图被挤出视野。布局参数按断点隔离,或从容器实际尺寸推导(见 `MapLibreCanvas.activePadding`)。
3. **占位符外露**:「待补充」从 markdown 正文一路渲染到 UI。数据层剔除 + 组件隐藏空区块(见 `stops-loader.ts` 的 `PLACEHOLDER_RE`)。
4. **脉冲泛滥**:同屏 5-6 个 `animate-ping/pulse`(marker、徽章、图标、图表点),违反 🔒 动效档;科幻 HUD 元素(「SENSORS ONLINE」绿 chip、雷达扫描圈、电流脉冲线)与远征叙事气质冲突,已移除。
5. **色板外刺痛色**:紫(`#d8b4fe`)、绿(`green-600`)、琥珀(`amber-*`)混进黄灰体系。新颜色进页面前先问:色板里有没有能用的?
6. **卡片套娃**:白卡→奶油卡→米色 chip→黄盒,四层边框包三行字。扁平定义列表即可(见 `CityPanel` 右栏)。

## 如何使用本文档(给 AI)

开发任意功能前:
1. **读 🔒** —— 列出这次会碰到的硬约束令牌,确保全部使用、零硬编码、中性色档位存在于上表。
2. **读 🧭** —— 想清楚如何延续这 6 条精神。
3. **看 🎨** —— 有现成模式就复用;先扫一遍反例清单确认没踩坑;是全新形态就自由设计,只需回到 🔒/🧭 自检。
4. 可视化对照页:`/elements`(中)/ `/en/elements`(英)。
