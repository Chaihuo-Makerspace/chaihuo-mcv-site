# /route 重构设计与实现

日期：2026-07-29 ｜ 状态：**已实现**（本文保留诊断与设计推导；文末「实现记录」列出落地位置与与原设计的差异）

> **2026-07-29 后续：脊线已移除。** 本文设计的"时间·海拔·故事密度"脊线（ExpeditionRidge）在当天晚些时候的二次重排中被整条砍掉：它的三个职责（时间轴 / 海拔 / 故事密度）分别与故事流和一个统计数字重复，是地图"被挤"的主因之一。海拔降级为顶部通栏的第五个统计数字（最高海拔）；真实时间比例这一独有价值移植给了故事流——卡片改为按真实日期定位（≥40px 最小间距、单向右推），最长的 ≥10 天静默段画成斜纹空白带。同时桌面端左栏改为顶部通栏 + 地图左上悬浮 chips，城市面板默认关闭且可收起为 48px 竖条。下文关于脊线的章节保留作设计史参考。

## 1. 诊断：地图为什么"没话说"

对着当前截图和数据逐条核：

**A. 一张图上有四种黄，等于没有黄**
已走过省份填黄、马年愿景线画黄、路线本身是黄褐、主题筛选芯片黄、面板里 6 个"阅读深度纪实"按钮还是黄。`DESIGN.md` 写着"探险黄只做小面积强调"，这一页正好是反例本身。眼睛进来找不到落点。

**B. 42 个点，每个点只携带 1 bit**
点的唯一区别是"去过 / 没去过"。同样是一个黄点，成都（13 篇日记、多场共创）和若羌（0 篇、纯过路）长得一模一样。地图上最贵的通道——**点的大小、填充、环色**——全部闲置。

**C. 时间维度完全缺席**
这是一次 2026.04.22 出发、至今 98 天、9590 公里的连续行进。页面却把它呈现成一张静态地理图：看不出先后、看不出快慢、看不出哪一段是三天狂奔、哪一段停了一个月（05.30 拉萨 → 06.28 乌鲁木齐，正好一个月的空白）。

**D. 海拔纵断面被塞进卡片当装饰**
从深圳 4m 爬到拉萨 4120m 再落回西安 400m——这是整趟旅程最有身体感的一条曲线，现在是面板里 100px 高的火柴盒，标题还被截断成"位于中国地势第二…"。

**E. 筛选器是死的**
点"科普 19 / 创客 23 / 产业 5"，地图上没有对应的视觉编码，用户不知道自己筛掉了什么。筛选器承诺了一个维度，地图不兑现。

**F. 川藏段标签糊成一团**
拉萨林芝波密邦达芒康理塘塔公成都雅安挤在一起。schema 里已有 `anchor` 字段，但没用来做标签分级。

**G. 版式把地图最值钱的地方盖住了**
标题卡浮在正上方、城市面板压在右侧——恰好压住华北华东，而路线的后半程（西安→太原→北京→赤峰）就在那儿。西部空地大片浪费。

**H. 面板是一串复读机**
西安 6 篇日记 = 6 张一模一样的卡 + 6 个一模一样的黄色按钮。信息密度低，视觉噪声高。

## 2. 核心判断

> **地图是图表，不是插画。**

这一页真正的资产不是"中国轮廓"，是三组已经存在、但没被画出来的数据：

1. **时间**（32 个 stop 有 event.date，最早 04.22）
2. **海拔**（每个 stop 都有，4m ↔ 4120m）
3. **活动密度**（51 篇日记已按城市归并，成都 13、西安 6、若羌 0）

重构的全部动作，就是把这三组数据从"藏在面板里的文字"变成"地图上可以一眼扫到的形"。

## 3. 版式重构

去掉浮在地图中央的标题卡，改成**左栏叙事 + 中央地图 + 底部时间带 + 右侧按需滑出**：

```
┌──────────────────────────────────────────────────────────────────┐
│ nav                                                              │
├────────────┬─────────────────────────────────────────────────────┤
│ 行程路线     │                                                     │
│            │                                                     │
│ 98天 9590km │                地图（整块留给它）                     │
│ 24省 42城   │                                                     │
│ 51篇日记     │                                       ┌───────────┐│
│ 最高4120m   │                                       │ 西安       ││
│            │                                        │ 选中才滑出  ││
│ ○足迹      │                                        │           ││
│ ○主题      │                                        │           ││
│ ○愿景      │                                        └───────────┘│
│            │                                                     │
│ 图例        │                                                     │
├────────────┴─────────────────────────────────────────────────────┤
│ 4m深圳 ▁▁▂▃▅███4120m拉萨███▅▃▂ ▁400m西安 ┊┈┈计划┈┈┊ 赤峰        │
│ 04.22          05.30                  07.24                      │
└──────────────────────────────────────────────────────────────────┘
```

关键改动：

- **左栏 320px 常驻**：页面身份 + 全局统计 + 视图切换 + 图例。不再浮层遮地图。
- **地图不再被右侧面板永久占位**：未选中时地图完整可见，选中才滑出面板（且面板可关）。
- **底部时间-海拔带全宽常驻**：见 §5，这是本次最大的新增。
- **数字用等宽体（tabular-nums）**：98 / 9590 / 42 / 4120 —— 这些数字本身就是叙事。

移动端：左栏统计压成一行横向 chips，时间带变成横向可滚动条，城市面板维持现有 bottom drawer。

## 4. 地图：从"图层堆叠"改成"三种模式"

现在所有图层同时开着，互相打架。改成互斥模式，一次只讲一件事：

| 模式 | 讲什么 | 视觉 |
|---|---|---|
| **足迹**（默认） | 走过哪里、什么时候、多热闹 | 路线按时间做明度梯度（早段浅、近段深）；点半径 = 日记数；当前位置一个脉冲 |
| **主题** | 科普 / 创客 / 产业 分布 | 点按主题着色（三色需在中性域内取，不再全黄）；无该主题的点降到 15% 透明；省份底色按活动量分档 |
| **愿景** | 2026 马年愿景线 | 马变成金色主角，真实路线退成灰线幽灵；这时候黄才允许铺开 |

**为什么把马做成模式**：现在它常驻，既看不出是马（尺度太大、被路线切割），又持续贡献噪声。给它一个专属模式，它反而第一次能被看清——用户主动点"愿景"，然后真实路线淡出、马亮起来，这是个有戏剧性的瞬间，比常年当水印强。

## 5. 时间-海拔带（新组件，本次重点）

把面板里那个火柴盒纵断面，提到页面底部做成全宽条带。它是地图的**第二视图**，同一批数据的另一个投影：

- **X 轴 = 时间**（有 event.date 的按日期定位，缺失的按序等分并用虚线区间表示"日期待补"）
- **Y 轴 = 海拔**（0–4200m，山脊形状即旅程体感）
- **每个 stop 一个刻度**，刻度上方一根细柱 = 该城日记数
- **已走过段实心填充，计划段虚线轮廓**
- **当前位置一个游标**（唯一允许的黄）
- **停留时长 = 刻度间距**：05.30 → 06.28 那一个月的空白会自己显形，这是数据自己在讲故事

**联动（brushing）**：
悬停地图上的点 → 时间带对应刻度高亮；悬停时间带 → 地图对应点高亮并轻微平移居中。两个视图互为索引，这是"表达力"的乘数。

拖动时间带 = 沿时间轴回放整条路线。（可作为 P2 加分项，非必需。）

## 6. 编码升级表：数据 → 视觉通道

| 数据（已有） | 现在的通道 | 提议通道 |
|---|---|---|
| visited | 线色 + 线宽 | 保留 |
| **行进顺序 / 时间** | 无 | 线的明度梯度 + 沿线稀疏方向箭头 + 时间带 X 轴 |
| **日记数（0–13）** | 无 | 点半径 3 档：0 篇 = 空心细环，1–3 = 实心小，4+ = 实心大（旁标数字） |
| **海拔** | 面板小图 | 底部时间带 Y 轴（主角） |
| **themes** | 筛选芯片（地图无反馈） | 主题模式下的点填色 / 三分环 |
| relationType（出发/教育/社区/产业） | 无 | 点内符号或环形笔触样式（低优先，别过载） |
| **停留时长** | 无 | 时间带刻度间距 |
| anchor | 未使用 | **标签分级**：默认只显示 anchor + 当前 + 选中，放大逐级揭示 → 直接治好川藏标签糊团 |
| province | 大面积黄填充 | 只保留描边 + 低对比暖灰调，或悬停时才浮出省名 |
| people / photos | 面板 | 保留，但**数据几乎为空**（全站 2 人 1 图），模块须条件渲染，绝不占位 |

## 7. 色彩修正（改动最小、收益最大的一条）

**黄的配额，全页只给三处**：
1. 当前位置点（含脉冲）
2. 选中态
3. 时间带的当前游标

其余一律降级：

- **省份填充**：取消荧光黄 `#f7e9bd`。改纸白 + 极低对比暖灰描边；"去过的省"若要区分，用比纸白**深半档的暖中性色**，不用色相。
- **路线（已走过）**：墨褐/深赭，比现在更接近墨水而非黄褐，让它从底图上真正跳出来。
- **路线（计划段）**：中性虚线，保持现状即可。
- **面板"阅读深度纪实"按钮**：全部去掉。整行卡片本身可点，右端一个外链角标。6 个黄块 → 0 个。
- **主题三色**：在暖中性域内取三档明度 + 极小色相偏移，不要三个饱和色相打架。

严格用 `theme.css` 令牌，不新增硬编码 hex；若需要新的中性档位，先补进 `theme.css`。

## 9. 数据缺口（决定了哪些模块值得做）

跑了一遍内容目录，实情：

| 项 | 状态 |
|---|---|
| stop 总数 | 43（含 1 个 routeOnly 返程点），已走过 38 |
| event.date | 32 个有，11 个无（拉萨→乌鲁木齐整段缺，正好是一个月空白那段） |
| 现场记正文 | 00–26 号完整；**27 号之后全是"待补充"** |
| 遇见的人 | 全站 **2 人**（柳州、毕节） |
| 照片 | 全站 **1 张** |
| 日记 | 51 篇语雀 + 18 篇本地，覆盖 18 座城；成都 13、西安 6、若羌等 0 |
| 里程（大圆弧近似） | 已走 9,590 km，全程 11,193 km |
| 海拔 | 4m（阳江）↔ 4120m（理塘一带） |

结论：**人物墙、照片流现在不值得设计**（数据不足会立刻退化成占位符，正是 `DESIGN.md` 的反例）。日记、海拔、时间、里程这四项数据充足，重构应该全押在这四项上。

补 11 个缺失日期是本次收益最高的内容工作——时间轴的完整度直接决定底部条带成不成立。

## 12. 实现记录（2026-07-29）

设计通过两版 HTML 示意稿验证后落地，代码位置如下。

### 新增

| 文件 | 作用 |
| --- | --- |
| `src/features/route-map/expedition-timeline.ts` | 时间轴：把 `event.date` 的松散写法（`2026.04.22` / `2026.04.24/04.25` / `2026.05.05–07`）归一成 ISO，缺失的按顺序在**内部**插值（尾部计划段不编日期），并派生第 N 天、里程、最高海拔等统计 |
| `src/features/route-map/ExpeditionRidge.tsx` | 时间-海拔脊：X=真实日期、Y=海拔、柱高=日记数，与地图共用一套选中态 |
| `src/features/route-map/StoryRiver.tsx` | 故事流：全部日记按时间横排，选中城市时其余淡出并自动滚动到位 |

### 改写

- **`MapLibreCanvas.tsx`** — 标签改由首页那套 `placeLabels()` 求解器排布（`map.project()` 取屏幕坐标，`zoomend`/`moveend`/`ResizeObserver` 后重算；偏移是相对屏幕像素，平移不需要重算）。新增照片钉：封面 + 城市名题注 + 日记数角标，位置用同一套成本函数求解，钉框再作为障碍物喂回 `placeLabels()`——被钉住的城不再单独排标签，同一个名字不出现两遍。点半径按日记数分三档。新增 `viewMode` 足迹/愿景。
- **`label-layout.ts`** — `placeLabels()` 加 `{ seed, skip }` 选项（种子占用框 / 跳过某些城）。算法本身零改动，首页调用点不变。
- **`map-style.ts`** — 省份荧光黄 `#f7e9bd` → 暖中性 `#ece5d2`；路线按 `t`（行程进度）做明度渐变 `#a99a5e → #5c4d08`，方向不用箭头也读得出；马年线默认 opacity 0，愿景模式才现身。
- **`CityPanel.tsx`** — 加前后城导航、`第 N 城 · 第 N 天 · 省 · 海拔 · 日期` 元信息行、关闭按钮；日记改「首篇大图 + 其余紧凑行」（原来 N 篇 = N 张同款卡 + N 个同款黄按钮）；海拔纵断面整体移除（已升格为底部脊）。
- **`RouteContent.tsx`** — 版式改左栏（身份 + 四个派生数字 + 视图切换 + 主题筛选）/ 地图 / 底部脊+故事流；城市面板改为选中才出现、可关闭。
- **`theme.css`** — 标记点改为以圆心定位、墨色点、按日记数分档；新增照片钉与引线样式；删除 `.mlc-compact`（低缩放一刀切隐藏标签），密度交给求解器。
- **`stops-loader.ts`** — 英文侧套话句 `"The detailed field note will be updated later."` 补进 `FILLER_RE`（它不含 "to be updated"，此前会直接印在 /en 面板上）。

### 与原设计的差异

1. **三模式砍成两模式**：只做「足迹 / 愿景」。「主题」模式与既有的主题筛选芯片重复，保留芯片即可。
2. **照片钉有预算**：钉数按地图面积计算（`bw*bh/24000`，上限 18），桌面 17 个是拼贴画，390px 手机上 6 个才读得动。
3. **马年线的隐藏用 `display` 而非 `opacity`**：MapLibre 的 Marker 会自己写内联 `opacity`，内联样式盖过 CSS 规则。
4. **首页地图未动**：`RoutePreview` 仍是原配色。它是本次标签方案的参照物，且用户明确认可现状。**代价是两张图的省份底色现在不一致**，后续如要统一，改 `RoutePreview.tsx` 里的 `fill` 即可。

### 落地时踩到的三个真问题

- **`position: relative` 打架**：给标记元素写了 `position: relative`，覆盖掉 MapLibre 的 `position: absolute`，标记退回文档流后再被 transform 平移，所有偏移整体偏了约 20px，南方几个钉被裁在地图边缘外。
- **零尺寸标记不可点也不可测**：把标记做成 0×0、只靠子元素显示，Playwright 判定为不可见，无障碍工具同理。改回 28px 圆形命中区。
- **国家级缩放下标记必然重叠**：手机上深圳/广州/阳江投影后只差 6–14px，任何 ≥12px 的命中区都会互相覆盖，真实点击永远落在最上面那个。这是地图固有属性，测试改为直接派发事件（`route-map-coordinates.spec.ts` 早就因同样原因这么做）。

### 首轮试用后的四处修正

1. **宽屏看不全地图**：地图行在宽屏上是 ~3:1 的扁视口，垂直装下中国需要约 140° 经度，而 `INTERACTION_BOUNDS` 只有 92° —— MapLibre 直接卡住缩放，南部（深圳/广州）被切。放宽到 `[[20,-12],[190,70]]`，`MIN_ZOOM` 2 → 1.4，并补上一直没启用的「回到全图」控件（`map.recenter` 这个 i18n key 早就存在，从未被用过）。
2. **右侧 400px 白留**：`fitPadding` 原本是常量，给城市面板留位；面板没打开时地图被白白推向左侧。改为跟随面板开合（`right: 400 / 56`）。
3. **「愿景」看不出是马**：按钮改名「马年愿景」，切换后左栏出一行说明「2026 全年路程走成一匹马」。
4. **故事流改成两段式**：dim 本身是对的，错的是"暗着还能直接跳外链"——看着像失效，点下去却离开了页面。现在：
   - **暗态**：卡片不是链接，一次点击**定位到那座城**（地图飞过去、脊上刻度亮起、面板切过去），图标是 `MapPin`
   - **亮态**（该城被选中）：卡片是真链接，点击打开日记，图标是 `↗`，封面带品牌色描边

   状态与行为从此一致：暗 = 还不能读，亮 = 可以读。标题右侧给一行提示「点暗色卡片先定位到那座城」。

另外主题筛选芯片从横向滚动改为换行：左栏只有 320px，滚动会把最后一个「产业 5」切成半个图标。
